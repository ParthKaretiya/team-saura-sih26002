# SauraRoute Shared Package

This directory is planned to contain types, models, constants, and validation schemas shared across services and apps in the monorepo.

## Planned Contents
* Type definitions for APIs, vehicles, incidents, routes, and risk predictions.
* GIS coordinate validation utilities.
* Common status code, role, and permission definitions.
* Base schemas (e.g., Zod or Joi schemas) shared between the Node API and frontends.
