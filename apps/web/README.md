# SauraRoute Web Operations Dashboard

This is the web frontend application for SauraRoute, built with React, Vite, TypeScript, and MapLibre GL JS.

## Current Status
* **Foundation Spike**: Minimal MapLibre GL JS map component initialized and centered on the North Eastern Region (NER) of India (`[93.5, 26.0]`).
* Free vector/raster demo tiles are utilized (no proprietary API key required for foundation testing).

## Scripts
* `npm run dev`: Start local development server (Vite) on http://localhost:5173
* `npm run build`: Typecheck and build production assets into `dist/`
* `npm run preview`: Preview production build locally
